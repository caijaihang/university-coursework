# Study Notes

## Python Basics

### Data Types
- `int` - Integer numbers: `1, 2, 3`
- `float` - Decimal numbers: `1.5, 3.14`
- `str` - Text: `"hello"`
- `bool` - True/False
- `list` - Ordered collection: `[1, 2, 3]`
- `dict` - Key-value pairs: `{"name": "Alice", "age": 25}`
